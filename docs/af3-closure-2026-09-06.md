# AF3 native-precision closure

Status: **completed for the nine-case, common-runtime, fixed-kernel panel**.
This is the first model under the
[upstream-first contract](precision-selection-protocol-2026-09-06.md).
Native BF16/operator policy is retained. One sampler multiplication's operand
order is restored to match the publisher's compiled graph; there is no precision
lowering. This is not publisher dependency-lock reproduction, independent
default-autotuning reproducibility, universal chemistry validation or a release.

## Completed results

The [nine-case report](../bench/experiments/af3-closure-2026-09-06.json)
passes **54/54 gates**: audited pair, uninstrumented pair, both observer bridges
and both first/warm repeats for every case. All **45 sample pairs** have exactly
equal coordinates. Each case's 12 raw output leaves and every extracted
confidence leaf are **bitwise identical**, including matching undefined values.
Inputs, effective configuration, 405 loaded parameter leaves and actual audit
RNG events match independently; separate executable caches are used.

The following are per-entity-instance maxima over five samples, after the same
whole-system Kabsch fit in each sample. No entity is refitted or rematched.
Residuals below are floating-point roundoff from fitting identical coordinates,

| Item | Both arms |
| --- | --- |
| Publisher | AlphaFold 3 v3.0.4, `85c4d20505fd5cef05eac22b534d4e793971ae69` |
| Reference runtime | Both arms use FoldJAX's installed runtime, not the publisher dependency lock |
| Hardware | Single NVIDIA RTX PRO 6000 Blackwell Max-Q, CUDA 13 |
| Compute | Native `global_config.bfloat16="all"`, preserving FP32 exceptions |
| Sampling | Five index-paired samples, 200 diffusion steps, 10 recycles (11 trunk passes) |
| MSA / batching | Native selection depth 1,024; original five-sample `hk.vmap`, no sample sharding |
| Matmul | Native `jax.default_matmul_precision=None`, no forced `highest` override |
| Inputs | Independently featurized native JSON, numeric and metadata exact |
| Shapes | Same publisher bucket grid, FoldJAX neutral padding disabled |
| Kernels | Triton attention; matched recorded Tokamax and XLA decisions for the parity gate |
| Coordinates | One proper all-valid-atom Kabsch per sample, RMSD per entity instance, no entity refit |
| Confidence | All raw heads and extracted fields; exact shape/dtype/order/masks and native NaN positions |

AF3 is already JAX upstream. This compares FoldJAX runtime integration and
retained patches, not a Torch rewrite. `bfloat16="all"` does not mean every
operation, parameter or coordinate is BF16. The numerical leaf diagnostic is
fixed at `atol=rtol=1e-4`; the coordinate diagnostic remains 0.05 Å per entity
in every sample. These are not a newly approved loss allowance for optional
precision lowering, whose structure/confidence criteria remain undecided.

The Tokamax autotune fallback is an explicit deviation from the publisher's
heuristic fallback: the local GPU has a documented shared-memory-incompatible
heuristic configuration. Both arms use the compatible policy. Generated CCD
assets and the C++ binary are shared and hashed; Python featurizers are separate.
This is not independent verification of two separate C++/CCD builds.

The native arm means **unmodified publisher Python executed on the common
FoldJAX runtime**, not an untouched publisher installation. The exact relevant
dependency differences are:

| Dependency | Publisher `pyproject.toml` pin | Both measured arms |
| --- | --- | --- |
| JAX / jaxlib | 0.10.2 (CUDA 12) | 0.11.1 (CUDA 13) |
| dm-haiku | 0.0.16 | 0.0.17 |
| Tokamax | 0.0.12 | 0.0.13 |
| RDKit | 2025.9.4 | 2026.3.5 |
| NumPy | Unpinned in `pyproject.toml` | 2.1.3 |

All measured runtime versions are bound into each provenance manifest. This
isolates FoldJAX's retained source/runtime-integration changes on its supported
environment. It does not establish that upgrading the publisher's dependency
lock leaves featurization, RNG, structure or confidence unchanged. A separate
publisher-locked environment comparison remains outside this closure claim;
the current project dependencies were not changed by this investigation.

Tokamax choices alone are insufficient: XLA also autotunes fused kernels.
The controlled producer records XLA decisions, and the consumer loads the
same decisions with `xla_gpu_require_complete_aot_autotune_results=true`.
JAX's automatic per-compilation-directory fusion cache is disabled for these
captures; compiled-executable caches remain separate. This follows the
[XLA persisted-autotuning mechanism](https://openxla.org/xla/persisted_autotuning).
No native compiled executable is copied into FoldJAX.

Removing observers changes 14 fusion keys in the 3GCA pilot. Strict loading of
only the audit cache correctly rejects that graph before outputs. The native
uninstrumented producer extends the cache for those new fusions; the bridge
checks hashes and preservation of every previous textproto record. The
uninstrumented FoldJAX consumer again requires complete cache coverage.
This does not waive coordinate or confidence gates. Independently autotuned
runs are a separate variability diagnostic, not this fixed-kernel proof.

## Actual randomness and measurement boundaries

The audit records actual JAX draw keys, dtypes, shapes and content hashes at
execution. It requires initial noise once, rotation/translation/churn 1,000
times each, and MSA Gumbel 11 times. It compares these event multisets exactly,
not just seed integers. This is an observed-tape identity check, not a serialized
noise array replay injector.

NumPy preprocessing normal/randint draws are recorded in consumption order,
including generator state identity. RDKit conformer seeds and returned
conformers are compared at the API boundary; RDKit's internal C++ PRNG stream
is not observable here. Final reference features must still match exactly.
Fixed-seed Fourier constants are covered by the independent source/runtime
identity, not counted as per-input sampler events.

Instrumented executions are not speed measurements. Separate uninstrumented
arms retain compile-inclusive first inference and synchronized warm inference,
including device/host output transfer. Their outputs must be compared both
against each other and against the corresponding audited outputs. A same-mode
repeat is also a separate runtime-stability control.
Parameter loading and hashing happen before the inference timer in the new
captures. They still contribute to process memory peaks. A compile-only speedup
must not be inferred from a producer that tunes versus a consumer that loads
already-recorded decisions. `--warm-repeats 5` additionally checks every repeated
raw output byte-for-byte outside the measured interval and reports a median.

Device memory is process allocator `peak_bytes_in_use`, including compilation/
autotuning activity; host memory is process `ru_maxrss`. Neither is a reset
warm-only live-tensor peak. Do not claim optimization benefits from audit times
or mix these definitions with unrelated measurements.

## Reproduction tools

`python -m bench.af3_closure_capture` accepts `native` or `foldjax`, plus
explicit `--input`, `--native-source`, `--weights` and a new `--out` directory.
The FoldJAX arm requires `--reference` pointing to the native capture and uses
the public prediction API. `--mode performance` disables the JAX observer and
retains first and repeated inference outputs. Queue GPU executions through tsp;
use immutable source snapshots and the run ledger. Never publish weights.
Run from the snapshot directory, not a live checkout: Python's `-m` lookup
places the working directory ahead of `PYTHONPATH`. The initial 3GCA fixed-XLA
pair used an unchanged, hashed live wrapper; later panel jobs use the actual
frozen directory as their working directory.

`python -m bench.af3_closure --left NATIVE --right FOLDJAX --out NEW_REPORT`
fails on missing evidence. `--output-only` is only the audited/unaudited output
bridge and explicitly grants no RNG admission.

`python -m bench.af3_closure_report --manifest CASE_PATHS_JSON
--artifact-base ARTIFACT_ROOT --out NEW_REPORT` aggregates six gates per case:
audit pair, uninstrumented pair, both observer bridges and both first/warm
repeats. It binds original artifact files and independent source-tree identities
by hash. Missing or failed gates cannot become a successful closure summary.

The initial pilot is RNA–ligand 3GCA. The completed finite output panel also
contains protein 1UBQ, protein–DNA 7R6R, protein–ligand 5SAK,
protein–protein 7ST3, protein–RNA 1URN and protein–RNA–ligand 3V7E.
The current panel also includes a populated RNA MSA (9GMW) and a nonempty
mapped template with ligand (9FM7). It remains finite, not all chemical inputs.
No crystal coordinates enter the parity measurements.
The 9FM7 input contains two 291-residue protein copies and two ligand copies;
its actual bucket is 768, not 512. The first template attempt mistakenly reused
the 512-token kernel manifest and failed strict Tokamax coverage before outputs.
Both that attempt and its dependent performance failure are retained. The retry
selects the already-prepared 768-token profile from actual feature shape, with
no input, dtype, schedule or tolerance change.

## Graph correction and compiler isolation

All 405 actually loaded parameter leaves matched in dtype, shape and bytes.
Without observers, native and carried StableHLO differed at only one operation:
native multiplied `noise_scale * noise`, whereas FoldJAX used `noise * noise_scale`.
The carried sampler now preserves native operand order. The entire resulting
StableHLO (excluding debug metadata) is byte-identical: 1,528,116 bytes, SHA256
`75723f6b90023765dfe9ad5a3fd56b8a96a6cae9b35eab6dbaf28b353b8013c0`.
The source-keyed AF3 runtime was rebuilt normally, including C++ and generated
assets; no cached runtime overlay was edited by hand.

This restores graph identity; it does **not** establish that commuting a
multiply alone caused all earlier coordinate/confidence drift. Earlier native
recompilations also differed. The full new control matches Tokamax **and** XLA
decisions, then compares independently executed native/public-FoldJAX arms.
The corrected 3GCA audit and uninstrumented bridge have exact coordinates and
raw/extracted confidence, including the first/warm repeat. No tolerance changed.

## Observer failure and control

The first full native capture aborted in XLA GPU fusion cost analysis before
outputs (`shape.IsArray() || shape.IsTuple()`, exit 134). A small AF3 sampler
control with a trivial denoiser reproduced the same failure with ordered
callbacks in seven seconds. The otherwise equivalent unordered-callback
control passed in eight seconds and observed all 3,001 sampler draws.

The observer was changed to unordered callbacks, retaining key/content event
identity. No AF3 arithmetic was changed. This isolates a compiler/observer
interaction, not a demonstrated model-port error. A subsequent native run
finished inference but failed its writer because the experimental manual C++
registration omitted the parent package attribute. The wrapper binding was
fixed, independently checked on CPU and rerun through successful output writing.
Failed lifecycle artifacts are preserved and never counted as closure.
